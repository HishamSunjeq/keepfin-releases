# Keepfin

Keep your media. Keepfin downloads video, audio, playlists and posts from YouTube, YouTube Music, TikTok, Instagram, X, SoundCloud and many more sites — locally on your own device, with no account and no tracking.

## Download

Get the latest version from **[Releases](https://github.com/HishamSunjeq/keepfin-releases/releases/latest)**:

| Platform | File | Notes |
|---|---|---|
| Windows (recommended) | `Keepfin-Setup-<version>.exe` | Installs Keepfin and updates itself from inside the app. |
| Windows (portable) | `Keepfin-Portable-<version>.exe` | Runs without installing; replace the file to update. |
| Android | `Keepfin-Android-<version>.apk` | Allow installing from your browser or file manager when Android asks. Later versions install over it and keep your downloads. |

Windows may show a SmartScreen warning because the app is not code-signed yet: choose **More info → Run anyway**.

## What it does

- Every quality a site offers — up to 8K and HDR — with the size shown before you download.
- Audio as MP3, M4A, Opus, FLAC or WAV with cover art and tags.
- Whole playlists, channels, albums and mixes, with selection.
- Spotify, Apple Music and Deezer links matched to the same recordings on YouTube Music.
- Private and age-restricted content after signing in.
- Subtitles, chapters, SponsorBlock and trimming.

Each release lists its changes. This repository only hosts the published downloads.
